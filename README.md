## 🧩 Features

### 🛒 Core Functionality
- **Product Listing:**  
  Displays products dynamically with images, prices, and descriptions.
- **Add to Cart:**  
  Users can add products to their shopping cart and view totals.
- **Remove from Cart:**  
  Allows removing specific products or clearing the entire cart.
- **Cart Quantity Management:**  
  Increase or decrease product quantities directly in the cart.
- **Persistent Cart (Optional):**  
  Cart data saved in **localStorage** to retain items on page reload.

### 🎨 Design & UX
- **Responsive Design:**  
  Optimized layout for desktop, tablet, and mobile screens.
- **Clean UI:**  
  Simple and intuitive user interface using HTML5 and modern CSS.
- **Product Cards:**  
  Visually appealing product display using flexbox or grid.

### ⚙️ Technical Details
- **HTML5:** Structure and semantics.  
- **CSS3:** Layout, animations, and responsive design.  
- **JavaScript (Vanilla):** Handles all logic — product management, cart updates, and DOM interactions.
